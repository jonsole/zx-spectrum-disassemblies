BB9D: Print a string in one colour
Used by the routine at DISPLAY_MENU.
Prints into the screen buffer (CALC_VIDBUF_ADDR) in the text font, colouring each character's cell straight into the attribute file with PRINT_ATTR. Each character covers the pixel rows from y down to y-7. As Knight Lore's print_text_single_colour, instruction for instruction; the rest is in PRINT_TEXT.
Input
HL the position: L = x, H = y, in pixels, y counting up from the bottom of the screen
DE the string, ASCII with bit 7 set on the last character
Output
DE the byte after the string
PRINT_TEXT_SINGLE_COLOUR BB9D PUSH HL the text font: FONT_BASE 384 bytes below the font at FONT, so that a letter's code lands on its glyph
BB9E LD HL,$6188
BBA1 LD (FONT_BASE),HL
BBA4 POP BC BC = the position again, left on the stack for TEXT_ATTR_ADDR; HL = its address in the buffer
BBA5 PUSH BC
BBA6 CALL CALC_VIDBUF_ADDR
BBA9 LD L,C
BBAA LD H,B
BBAB LD A,(PRINT_ATTR) the colour into A'
BBAE EX AF,AF'
BBAF JR TEXT_ATTR_ADDR
