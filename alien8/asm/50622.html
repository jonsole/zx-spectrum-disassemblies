C5BE: Do two objects overlap in V?
Used by the routines at DO_ANY_OBJS_INTERSECT, CAN_PICK_UP, ADJ_DU_FOR_OBJ_INTERSECT, ADJ_DV_FOR_OBJ_INTERSECT and ADJ_DZ_FOR_OBJ_INTERSECT.
DO_OBJS_INTERSECT_ON_U for V, with the mover's dV in L and the half-sizes at +$05. Also used by DO_ANY_OBJS_INTERSECT and CAN_PICK_UP.
Input
IX the moving object
IY the other object
L the mover's dV
Output
F carry set if they overlap
DO_OBJS_INTERSECT_ON_V C5BE LD A,(IX+$05) D = the two half-sizes
C5C1 ADD A,(IY+$05)
C5C4 LD D,A
C5C5 LD A,(IX+$02) A = |V + dV - the other's V|
C5C8 ADD A,L
C5C9 SUB (IY+$02)
C5CC JP P,DO_OBJS_INTERSECT_ON_V_0
C5CF NEG
DO_OBJS_INTERSECT_ON_V_0 C5D1 SUB D Carry if less than D
C5D2 RET
