CE4E: Clear all 56 object records
Used by the routine at GAME_ENDED.
1792 bytes from OBJECTS, the robot's records included: used when a game has ended (GAME_ENDED). The entry point CLR_MEM clears BC bytes from HL, and CLR_BYTE fills them with E; the start of a game clears the variables and records with CLR_MEM (START, AFTER_GAME). As Knight Lore's clr_mem and clr_byte.

HL (CLR_MEM, CLR_BYTE) the first byte
BC (CLR_MEM, CLR_BYTE) how many
