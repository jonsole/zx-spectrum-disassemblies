8180: Mark one height's blocks in PLANES
Used by the routine at BUILD_PLANES.
For each of the 512 places in PLANES, write the height's bit there if the gathered cell at the same offset from DE has a block at that height. Called for the heights in order, lowest first, so a higher block overwrites a lower one.
Input
C The height's bit ($01 for the ground layer up to $20)
DE Where in VIEW_CELLS that height's cells start
