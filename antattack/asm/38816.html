97A0: Type RUN and run it
Used by the routine at LOADED.
Clears the error, resets the stack from ERR_SP, puts RUN and ENTER in the edit line and jumps into the ROM's line executor. This is also how the game starts after loading, since the tape's program header has no auto-run line.
