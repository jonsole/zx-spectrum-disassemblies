776B: What is in room $0F

As a new game sets it out, drawn by the game itself.
4 records, then a zero to end the list. Add $8A83 to each to get where it ends up at run time.
Also here when a game starts, found by their own room byte rather than named in the list: food.
ROOM_LIST_0F 776B DEFW DOOR_R0F_R0E A door to room $0E
776D DEFW DOOR_R10_R0F A door to room $10
776F DEFW GREEN_DOOR_R0F_R6D A green door to room $6D
7771 DEFW A_C_G_SHIELD_R0F_R11 An A.C.G. shield
7773 DEFW $0000 End of the list
