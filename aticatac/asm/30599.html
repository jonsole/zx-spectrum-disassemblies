7787: What is in room $12

As a new game sets it out, drawn by the game itself.
3 records, then a zero to end the list. Add $8A83 to each to get where it ends up at run time.
Also here when a game starts, found by their own room byte rather than named in the list: food.
ROOM_LIST_12 7787 DEFW DOOR_R12_R11 A door to room $11
7789 DEFW DOOR_R13_R12 A door to room $13
778B DEFW WALL_ANTLERS_R0E_R12 A wall trophy
778D DEFW $0000 End of the list
