785D: What is in room $28

As a new game sets it out, drawn by the game itself.
2 records, then a zero to end the list. Add $8A83 to each to get where it ends up at run time.
Also here when a game starts, found by their own room byte rather than named in the list: food.
ROOM_LIST_28 785D DEFW DOOR_R27_R28 A door to room $27
785F DEFW CYAN_DOOR_R28_R29 A cyan door to room $29
7861 DEFW $0000 End of the list
