7909: What is in room $3D

As a new game sets it out, drawn by the game itself.
5 records, then a zero to end the list. Add $8A83 to each to get where it ends up at run time.
ROOM_LIST_3D 7909 DEFW CAVE_DOOR_R3B_R3D A cave door to room $3B
790B DEFW CAVE_DOOR_R3D_R3E A cave door to room $3E
790D DEFW CYAN_CAVE_DOOR_R3D_R3F A cyan cave door to room $3F
790F DEFW BOOKCASE_R3D_R49 A bookcase (the wizard only) to room $49
7911 DEFW BARREL_STACK_R91_R3D A barrel stack
7913 DEFW $0000 End of the list
