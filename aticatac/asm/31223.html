79F7: What is in room $5B

As a new game sets it out, drawn by the game itself.
6 records, then a zero to end the list. Add $8A83 to each to get where it ends up at run time.
Also here when a game starts, found by their own room byte rather than named in the list: food.
ROOM_LIST_5B 79F7 DEFW DOOR_R5A_R5B A door to room $5A
79F9 DEFW RED_DOOR_R5B_R5C A red door to room $5C
79FB DEFW DOOR_R57_R5B A door to room $57
79FD DEFW GREEN_DOOR_R5B_R5F A green door to room $5F
79FF DEFW YELLOW_DOOR_R66_R5B A yellow door to room $66
7A01 DEFW TABLE_R5B_R5C A table
7A03 DEFW $0000 End of the list
