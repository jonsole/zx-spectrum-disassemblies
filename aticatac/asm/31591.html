7B67: What is in room $81

As a new game sets it out, drawn by the game itself.
3 records, then a zero to end the list. Add $8A83 to each to get where it ends up at run time.
ROOM_LIST_81 7B67 DEFW DOOR_R82_R81 A door to room $82
7B69 DEFW DOOR_R81_R7F A door to room $7F
7B6B DEFW TABLE_R7A_R81 A table
7B6D DEFW $0000 End of the list
