7CEA: The title screen's menu
Three tables and then the words. The seven lines are drawn by DRAW_MENU, which walks the colours and the row positions in step and takes each string in turn; a character with bit 7 set ends a string, which is why there are no lengths anywhere.
The last two strings are not part of the seven and carry their own colour byte in front, so they can be printed on their own.
MENU_DATA 7CEA DEFB $45,$45,$45,$45,$45,$45,$47 The colour of each line -- six in $45 and the last in $47, which is what makes START GAME brighter than the choices above it.
7CF1 DEFB $10,$28,$40,$58,$70,$88,$A0 The row each is drawn at, 24 pixels apart.
7CF8 DEFM "1 KEYBOAR",$C4
7D03 DEFM "2 KEMPSTON JOYSTIC",$CB
7D17 DEFM "3 CURSOR JOYSTIC",$CB
7D2B DEFM "4 KNIGH",$D4
7D34 DEFM "5 WIZAR",$C4
7D3D DEFM "6 SER",$C6
7D44 DEFM "0 START GAM",$C5
7D51 DEFM "G%1983 A.C.G. ALL RIGHTS RESERVE",$C4 The copyright line. "%" is the copyright sign in this font, not a per cent.
7D72 DEFM "GATICATAC GAME SELECTIO",$CE
