7D9A: Set a new game up
Used by the routine at TITLE_SCREEN.
Clears the variables, sets the lives to three, points the cursor at $EB58, blanks the screen and goes on to build the castle. Everything a game needs to be true at its first frame is made true here.
START_GAME 7D9A CALL CLEAR_VARIABLES
7D9D LD A,$03
7D9F LD ($5E21),A
7DA2 LD HL,$EB58
7DA5 LD ($5E55),HL
7DA8 CALL CLEAR_SCREEN
7DAB CALL DRAW_SCROLL
7DAE CALL DRAW_LIVES
7DB1 CALL ROTATING_INDEX
7DB4 CALL PLACE_KEYS
7DB7 CALL LOAD_INITIAL_STATE
7DBA CALL SCAN_DOORS
7DBD CALL PLACE_PLAYER
7DC0 JP ARRIVE_IN_ROOM
