7E93: Dispatch a record named in a room's list
Takes an entry as ROOM_CONTENTS stores it, subtracts the $757D bias to get the real address, puts it in IX and dispatches it -- pushing a return address first, the same convention MAIN_LOOP uses.
DISPATCH_FROM_LIST 7E93 LD BC,$7E35
7E96 PUSH BC
7E97 LD BC,$757D
7E9A AND A
7E9B SBC HL,BC
7E9D PUSH HL
7E9E POP IX
7EA0 LD A,($EA91)
7EA3 CP (IX+$01)
7EA6 JR Z,DISPATCH_FROM_LIST_0
7EA8 LD BC,$0008
7EAB ADD IX,BC
DISPATCH_FROM_LIST_0 7EAD LD HL,$802A
7EB0 JR DISPATCH_ACTOR_1
