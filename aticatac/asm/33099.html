814B: Fire, for one of the other characters
Instruction for instruction the same as TRY_FIRE -- refuse if a shot is already in the air, refuse if $5E2D says not now, make a noise, launch -- but it calls SOUND_SWEEP_DOWN where the other calls SOUND_SWEEP_UP. Each character has its own copy of this so that each can have its own firing sound, rather than one routine taking a parameter.
