8D61: Put the castle back the way it started
One LDIR of $1570 bytes from $600D to $EA90. Everything the game keeps at run time -- the player's record, the objects, the monsters, the doors, all of it -- exists as a template inside the loaded block and is copied wholesale into the working area.
So the runtime tables that do not appear in this disassembly, because they live above $D600, do appear in it after all: as five and a half kilobytes of data starting at $600D, waiting to be copied. Starting a new game is a single block move.
LOAD_INITIAL_STATE 8D61 LD HL,$600D
8D64 LD DE,$EA90
8D67 LD BC,$1570
8D6A LDIR
8D6C RET
