9710: What it says when you escape
Two strings, each a colour byte then the text, with bit 7 on the last character. The first is misspelt: the bytes read CONGRATULATION and then $D4, which is "T" with the end marker set, so the screen says CONGRATULATIONT. Drawing the screen confirms it -- this is what the game shipped with, not a mistake in reading it.
END_MESSAGES 9710 DEFM "GCONGRATULATION",$D4
9720 DEFM "GYOU HAVE ESCAPE",$C4
