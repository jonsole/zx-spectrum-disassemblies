9731: The sequence played when the player gets out
Runs 128 times: each pass beeps a note whose pitch comes from the frame counter at $5C78, picks black or white from bit 3 of it, writes that into two cells of the attribute file and then floods the rest outwards with SPIRAL_FILL. So the screen flashes in and out from the middle while the note climbs. It ends by jumping straight back into the main loop at $9117.
Never reached in any of the recorded playthroughs, which is why the code map left it as data until it was disassembled by hand.
