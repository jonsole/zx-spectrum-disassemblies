9ABA: Point at the bottom row of a sprite
Multiplies the width by the height less one and adds it to the data pointer, so drawing can start from the far end. Called by every drawing routine whose mode number has bit 2 set -- which is how the eight modes divide: the low two bits choose the horizontal treatment and bit 2 turns the sprite over.
Checking all sixteen routines in the two tables bears that out exactly. Modes 0 to 3 leave the pointer where it is; modes 4 to 7 all begin by calling this.
