9BA2: Convert pixel coordinates to a display file address
Used by the routines at PRINT_MENU_LINE, DRAW_FOOD, TICK_CLOCK, DRAW_SUMMARY, FETCH_SPRITE, PIXEL_MASK, SETUP_ERASE, SETUP_SPRITE_DRAW, ERASE_STRIP, ADD_SCORE, PRINT_STRING and DRAW_SCROLL.
The standard 48K display address computation, done in place on HL. Builds $4000 + ((y AND $C0) << 5) + ((y AND $07) << 8) + ((y AND $38) << 2) + (x >> 3).
Input
HL On entry H = y (0-191), L = x. On exit, the display file address of that pixel's character cell.
PIXEL_TO_SCREEN 9BA2 LD A,L x >> 3 gives the character column; (y AND $38) << 2 the row within the third.
