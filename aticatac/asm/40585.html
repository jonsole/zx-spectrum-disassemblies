9E89: Find a sprite's graphics
Used by the routines at MATERIALISING, DYING, LOSE_LIFE and SPRITE_OF_ACTOR.
Sprite numbers are 1-based, so one is taken off before doubling into SPRITE_TABLE. This is the lookup the general drawing path uses, and it is the one that covers every sprite in the game -- the catalogue of pictures is built by driving this path, which is why it can draw codes right across the range.
Input
A The sprite number
DE On exit, that sprite's graphics
SPRITE_ADDRESS 9E89 DEC A Numbered from 1, two bytes an entry.
9E8A LD L,A
9E8B LD H,$00
9E8D ADD HL,HL
9E8E LD BC,SPRITE_TABLE The table.
9E91 ADD HL,BC
9E92 LD E,(HL) The address it holds.
9E93 INC HL
9E94 LD D,(HL)
9E95 RET
