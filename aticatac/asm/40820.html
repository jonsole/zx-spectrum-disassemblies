9F74: Set up the drawing address in both register banks
Runs the same setup twice, once per bank, keeping DE across the first call so the second gets the same argument, and then joins the erase path at $9FD1.
Like NEXT_PIXEL_ROW, nothing reaches it: no call, no jump, no table entry. SETUP_ERASE immediately after it is the version the game actually uses.
SETUP_BOTH_BANKS 9F74 PUSH DE DE is wanted twice, so it is kept over the first call.
9F75 CALL SETUP_ERASE_0
9F78 EXX The second bank gets the same argument.
9F79 POP DE
9F7A CALL SETUP_SPRITE_DRAW_0
9F7D EXX
