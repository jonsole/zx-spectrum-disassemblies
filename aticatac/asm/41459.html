A1F3: Print a string of tiles in a single colour
Draws consecutive tiles left to right, writing one attribute byte per cell as it goes. It keeps the display address and the attribute address live at the same time in the two register banks, swapping with EXX between the pixel write and the colour write rather than recomputing either.
Input
HL H = y (0-191), L = x -- where to start
DE The string: one attribute byte, then the tile codes. Bit 7 set on a code marks it as the last one.
PRINT_STRING A1F3 PUSH HL
A1F4 CALL PIXEL_TO_SCREEN Display address into the main bank...
A1F7 LD A,(DE) The first byte is the colour, not a character; it is kept in A' for the whole run.
A1F8 EX AF,AF'
A1F9 INC DE
A1FA EXX
A1FB POP HL
A1FC CALL PIXEL_TO_ATTR ...and the attribute address into the alternate one.
This entry point is used by the routine at PRINT_MENU_LINE.
