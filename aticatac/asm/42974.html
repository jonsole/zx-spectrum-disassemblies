A7DE: Colours for a graphic, entry $C9, $EB of the attribute table
One attribute per character cell, 4 across by 3 down, behind the graphic this entry pairs with. The first two bytes are the width and the height.
Shared by 2 codes, which is how the game gets a mirrored or repeated frame without a second copy of the picture.
