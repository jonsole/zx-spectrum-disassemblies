B03A: The character set the status panel is drawn from
94 characters, eight bytes each, top row first. DRAW_PANEL points the tile source at this and then draws 8 columns by 24 rows from PANEL_LAYOUT, so the parchment scroll down the right of the screen is not a bitmap at all -- it is a little character set, and a 192-byte map naming which piece goes in each cell.
Running DRAW_PANEL and photographing the screen settles what it draws: the scroll, with the words TIME and SCORE on it and the compass at its foot. An earlier note here called it the title picture, which it is not.
That the count is exactly 94 is confirmed by the map: the highest value in it is $5D, which is 93, the last character here.
