CONGRATULATIONT
$971F holds $D4. Bit 7 is the end-of-string marker, so the character is $54 -- "T" -- where it should be $53, "S". The screen a player sees on escaping the castle reads CONGRATULATIONT. It is not a misreading of the data. Both pictures below were drawn by running the game's own end-of-game routine at SHOW_END_SCREEN, and the only difference between them is that one byte.
As it ships
With $971F set to $D3
It survived because almost nobody saw it. Reaching this screen means finishing the game: getting through the A.C.G. door, with all three pieces of its key, into room $8E, which MAIN_LOOP checks for on every pass before it jumps to SHOW_END_SCREEN. A machine playing the game at random never gets there, and a code map built from playthroughs classified the whole routine as data until it was picked apart by hand.
