Tiles: every tile of the map

The 171 tiles of the planet, each drawn on its own by the game. A tile number picks a word in tile_table, the address of the tile's record in tile_records, which draw_landscape reads: a list of pieces, each a straight run of identical steps in one of sixteen directions, chained end to end across the page. The planet links each map cell here.

A tile record

BytesWhat
0An empty tile: nothing is drawn. 4 tiles point at an empty record ($00, $20, $2A, $A6).
$99 (optional)The tile is turned upside down: each direction goes through upside_down_table (floors become ceilings), a flat piece's y is moved by XOR $0C and its end codes by XOR 1 (piece_ends).
$FF (optional)The tile is mirrored left to right: each direction goes through mirror_table, x is reflected across the page, a flat run starts from its other end and its end codes swap sides (XOR 2) -- except a flat piece whose right end code is $16, which is left alone.
$95-$FF (optional)Skipped: padding.
countThe number of pieces, 1 to 6 in the tiles that have any (a collision-box list has room for seven).
x, yEach piece's start in the page: its lowest point, x from 8 and y from $18 down the page.
direction, stepsHigh nibble the direction, low nibble the number of steps (0 is 16), read by load_piece_steps.
two end codesOnly for a flat piece (directions 0 and 7): the codes of its first and last step, which pick end caps, a drop or a lip (draw_flat_end_lip). The values used: $00, $10-$13, $16.

The markers let four tiles share one record: a plain record at A can be pointed at from A-1 with $99 before it (upside down), from A-2 with $FF $99 (the $99 is then padding: mirrored) and from A-3 with $99 $FF $99 (both).
