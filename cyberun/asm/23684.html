5C84: Bit-doubling table
Sixteen bytes, one for each value of a nibble: each of the nibble's four bits doubled into a pair, so that bit n of the index sets bits 2n and 2n+1. print_char_double prints characters twice as wide this way (and twice as tall, by writing each row twice), looking up each half of a font byte: it adds the nibble to $84 with B holding $5C, so the table has to sit within one page.
double_bits 5C84 DEFB $00,$03,$0C,$0F,$30,$33,$3C,$3F
5C8C DEFB $C0,$C3,$CC,$CF,$F0,$F3,$FC,$FF
