5E17: The things lying in the world: their places
Two bytes for each of the 290 objects, in the same order as map_object_kinds. Their column is the one map_objects_per_column puts them in; these give the rest, as spawn_objects_from_list unpacks them into an object slot.
First byte: bits 2-7, less 1, the y within the map cell (slot +5); bits 0-1 are bits 3-4 of the x within the cell. Second byte: bits 5-7 are bits 5-7 of the x (slot +2), and bits 0-4 the map row, 1-28 (slot +4). An object is put into a slot only when its row is the screen's map row or the one below.
