7303: Sound the rocket's launch
Used by the routine at draw_rocket.
Called by draw_rocket each pass while the rocket is launching, with the pass counter's low two bits. C = (A + 2) x 4 clicks, 8 to 20, and the scramble (NOT C + 6) AND $1F (crackle), so the roar changes from pass to pass.
Input
A 0-3
sound_launch 7303 ADD A,$02 C = 4(A + 2)
7305 ADD A,A
7306 ADD A,A
7307 LD C,A
7308 CPL The scramble from C
7309 ADD A,$06
730B AND $1F
730D LD E,A
730E JP crackle
