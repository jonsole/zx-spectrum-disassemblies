731F: Rocket part: a barred band
As the compositor draw_sprite_pair draws it in play (three times the size; sprites have no colour of their own).
The sprite graphics, from here to the code at landscape_end_pieces, mostly in the form width in bytes, height in lines, then the lines bottom line first, with no mask. The ship's add-ons 1-9 (addon_bar_graphic describes them) also have a height byte before and $FF or a mask after; the five pictures from puff_graphic (the jets') and the four frames from ring_graphic (the special beam's) have a height byte only. Which object shows which picture is set by the per-type table in object_handlers: each type's word points at a list of frame addresses, and the record's +$13 (low nibble) picks the frame. Names here describe what each picture looks like; what the scenery pictures are in the game is not yet worked out.
3 bytes by 8 lines, no mask, bottom line first. Type $1E's frame 0. The rocket parts are type $1E, and a part's frame is its number.
