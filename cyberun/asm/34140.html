855C: Which spawn points each tile allows
One byte for each tile number: bit n set allows spawn point n (spawn_points) in a map cell holding that tile. start_attacker takes the tile of the cell it will put an attacker in from the four tile bytes at map_window_tile_bytes (the four cells the view overlaps, which load_map_window keeps from the map), and tries the allowed points starting from a random one. The table covers tiles $00-$A8; the map's one cell of tile $A9 reads its mask from the first byte of spawn_points, and $AA, which load_map_window puts in place of $3E during the fly-in (map_rebuild bit 7), the second.
This is level data: a build-time generator should lay it out by tile number, with the tiles.
