8615: Run the menu until 0 is pressed
Used by the routine at menu.
Called by the menu (menu) after the title tune. Each pass: a new random number (random), the pass counter (in object_records) up by one, the two players' control-method pointers moved (move_method_arrow), the one-or-two-player lines coloured (colour_player_line, which flashes the chosen one), a pause of $18 x 255 loops (delay), and then key 0 ends it; otherwise the menu's keys are read (menu_keys) and round again.
Like every keyboard read in the game, the port is selected with OUT ($FD) first.

8618 LD HL,(pass_counter) Count the pass

861F LD IX,player1_pointer Move player 1's pointer, then player 2's
