8FBF: The ship icon's colour patch
The patch record fill_attributes paints over the current player's ship icon (contact_damage): width 4 characters, height 2, and the colour, which contact_damage writes. The fourth byte is a $C9 that nothing uses.
icon_patch_record 8FBF DEFB $04,$02,$00,$C9 Width, height, colour; and an unused byte
