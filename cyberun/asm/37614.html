92EE: The homing missiles' target values
By type less $13 (find_missile_target adds one to the type to test for a free record before it subtracts $14), the indexing of type_points, and in the order of the points there: $13 (a cloud) 0, $14 (the rotor craft, 250 points) 8, $15 (debris) 0, $16 (the saucer, 200) 7, $17 (the eye pod, 150) 6, $18 (the pillar, 100) 5, $19 (the tough attacker, 75 a hit) 2, $1A (the dome, 90) 4, $1B 0, $1C (bullets and other thrown things) 0, $1D (rocks, 350) 9, $1E (a falling rocket part) 0. A value of 0 is never picked, so a cloud, which can come into records 0-3 through the wave table, reads the table's first byte and is passed over, as are debris, thrown things and rocket parts.
In 240 seconds of simulated flying with missiles, run for the reference pages, all 285 targets chosen were the best on the screen by this ranking, and clouds, debris and bullets were never chosen.
