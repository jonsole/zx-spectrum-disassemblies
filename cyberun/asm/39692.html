9B0C: The notes
61 entries of three bytes (play_note): the half-period's delay count as B then C (the DJNZ count, then the number of passes round it, so about 256*(C-1)+B steps of 13 T-states), then the cycles in one unit of length. Entry 0 is unused (note 0 is a rest). Entries 1-60 rise a semitone each in loop counts -- 256*(C-1)+B is equal-tempered to within 7 cents -- except that entry 18 has entry 17's delay (only its cycle count differs), so note 18 sounds as note 17. Each half-wave also spends a fixed time outside the loops, which bends the scale played from 37 cents sharp at entry 1 to 34 cents flat at entry 60, from about 53 Hz up to 1524 Hz (measured in SkoolKit's simulator for the Sounds page). The cycle counts rise with the pitch so that a unit lasts about the same time.
