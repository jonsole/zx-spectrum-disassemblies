A0CB: Copy a character's rows up the screen
The normal size: seven rows, the bottom first, each a line above the last (line_up_hl). Then the colour in the other register set's B goes into the attribute at its HL, which moves on; and HL moves to the next character cell.
Input
DE The character's bytes
HL The screen address of its bottom row
B 7
print_char_rows A0CB LD A,(DE) Seven rows, upwards
A0CC LD (HL),A
A0CD INC DE
A0CE CALL line_up_hl
A0D1 DJNZ print_char_rows
A0D3 EXX Its colour
A0D4 LD (HL),B
A0D5 INC HL
A0D6 EXX
A0D7 POP HL The next cell; DE back to the code
A0D8 INC HL
A0D9 POP DE
A0DA RET
