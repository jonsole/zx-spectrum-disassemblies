A0DB: Print one character at double size
The double-size half of the character printer print_char, reached through its self-modified JR at the end of print_char when print_string has patched that JR's displacement to $10 for a string whose attribute byte has bit 7 set. Each of the glyph's seven rows (stored bottom row first) is split into its two nibbles; each nibble is doubled to a whole byte through the table double_bits (bit n of the nibble becomes bits 2n and 2n+1), and the two bytes are written side by side on two pixel lines, so the character comes out 16 pixels wide and 14 lines high, drawn upwards from the line HL starts on.
HL must start on an odd pixel line within its cell (normally the bottom line, 7): the plain DEC H between the two lines of each row never crosses a cell boundary only because each pair starts on an odd line. Then a 2x2 block of attributes is coloured: the cell, the cell above, and the two to their right.
Input
DE The glyph (7 bytes, bottom row first)
HL Screen address of the character's bottom-left byte
B' The attribute
DE' 32, one attribute row
HL' Attribute address of the character's bottom-left cell
