A115: Print a string
Used by the routines at print_strings, planet_secured, test_player_shots, print_lives, show_player and game_over.
Prints one string record and returns DE pointing at the next, so a list of strings can be printed by calling this again. The record is: x in pixels, y in pixels (the pixel line the characters' bottom rows go on), an attribute byte, a character count, and that many character codes. Bit 7 of the attribute byte asks for double size (print_char_double); the other seven bits are the colour, so a string can never FLASH. Character n's glyph is the seven bytes at font plus 7n, bottom row first.

DE The string record
