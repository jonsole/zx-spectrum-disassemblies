A1C3: Move HL up one pixel line
Used by the routines at dissolve_play_area, clear_play_area, print_char_rows, print_char_double, toggle_carried_part, draw_beam, erase_laser, draw_bitmap, draw_frame, draw_fuel_gauge, draw_flat_end_lip, fill_up_past_step, fill_row_pair, start_landscape and fill_under_slope.
Moves a screen address one pixel line up the screen: the line above within the cell, or the bottom line of the cell above, crossing into the third above when the row was the top of a third. Everything in the game draws bottom-up -- the graphics are stored bottom row first -- so this, and copies of it written inline in the sprite routines, are what step the drawing. About 47 T-states with the CALL, most of the time.
Input
HL A screen address
Output
HL The address one pixel line above
