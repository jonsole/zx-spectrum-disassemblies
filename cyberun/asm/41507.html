A223: Read a graphic's header for the compositor
Used by the routines at new_sprite_header and old_sprite_header.
A graphic is a width in bytes and a height in rows, then the rows, bottom row first, each the width in bytes, left to right; there is no mask. This also returns in C the index into the row-routine tables erase_row_routines and draw_row_routines: the width less one when the sprite is drawn shifted (x AND 6 not zero), the width plus four when it is byte-aligned -- so 0-4 are the shifted routines for widths 1-5 and 5-10 the aligned ones for widths 1-6.
Input
DE The graphic
L The x it is to be drawn at
Output
H Width in bytes
B Height in rows
C The row routine's index
DE The first row
