A234: Set up the old image's erase
Used by the routines at prepare_erase and draw_star_layer.
Records the old image's height (old_sprite_rows) and width (sprite_width, which draw_sprite_pair turns to pixels) and chooses the routine that rubs one of its rows out of the buffer (erase_row_routines) into IY, and its shift table page into B.
Input
B Height
H Width in bytes
C Row routine index (read_graphic_header)
Output
IY The erase-row routine
B The shift tables' page (shift_page)
set_old_sprite A234 LD A,B
A235 LD (old_sprite_rows),A
A238 LD A,H
A239 LD (sprite_width),A
A23C LD HL,erase_row_routines
A23F CALL table_word
A242 PUSH HL
A243 POP IY
A245 JR shift_page
