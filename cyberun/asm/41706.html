A2EA: Start a new sprite pair: no old image, no new image
Used by the routines at update_objects, move_missile, draw_rocket, update_ground_objects and draw_star_layer.
Called before each object's erase and draw is set up: both heights (old_sprite_rows, new_sprite_rows) and both widths 0, and the left-clip flag (sprite_left_clip) clear.
clear_sprite_pair A2EA LD HL,$0000
A2ED LD (old_sprite_rows),HL
A2F0 LD (sprite_width),HL
A2F3 XOR A
A2F4 LD (sprite_left_clip),A
A2F7 RET
