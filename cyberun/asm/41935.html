A3CF: Copy a clipped row into the buffer
The row loop of the clipped copy into the buffer, for a box straddling the left edge of the play area: entered from the DJNZ at the end of draw_sprite_pair, so many LDIs before the end of this chain as there are bytes on the screen, then the rest of the buffer's row skipped and the screen address moved up a line. The first LDI is reached only with the full six bytes, which never happened in the build's sessions.
copy_in_clipped A3CF LDI Copy the row's bytes from the screen to the buffer (C is $FF, so the LDIs never touch B)

A3DB LD A,$00 Skip the part of the buffer's row left of the edge (the LD's operand is patched by draw_sprite_pair)
