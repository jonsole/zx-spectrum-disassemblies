AF25: The update routines for object types $13-$1E
Twelve words, the update routines for object types $13 to $1E: run_sky_object_handler jumps through them by the record's type less $13. Type $1B's entry is type1b_graphics, a list of graphics, not code: a type $1B object updated through here would crash, so presumably none is. Type $1E, a rocket part falling into place, is update_rocket_part.
