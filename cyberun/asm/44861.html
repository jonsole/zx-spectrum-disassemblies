AF3D: The graphic list of every object type
One word for each object type from 0 to $1E: the address of a list of graphics, which object_graphic indexes by the low four bits of the record's +13 (the frame) and graphic_frame_list reads the first of. Each graphic is a byte of its width in bytes, a byte of its height in lines, then the rows, bottom row first.
Type 0, the shots' missile, is missile_frames; type $0C, the add-ons lying on the planet, shares the ship's list of add-on graphics (addon_graphics); the lists of types $0D, $14, $1B and $1E follow below (type0d_graphics, type14_graphics, type1b_graphics, rocket_part_frames).
