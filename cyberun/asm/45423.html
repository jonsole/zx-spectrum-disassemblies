B16F: Read the current player's control method
Used by the routine at read_controls.
By the method in the current player's record (control_method): 0 keyboard, 1 Kempston, 2 cursor keys, 3 Interface II. Every method gives C in the Kempston layout -- bit 0 right, 1 left, 2 down, 3 up (thrust), 4 fire -- plus bit 5, the special key, which fires the special beam (special_beam_key). On the keyboard the special key is the number row; with a joystick it is any letter key but CAPS SHIFT and SPACE (read_keyboard masks the five keys of each half-row).
The keyboard: right is X, V, N or SYMBOL SHIFT, left Z, C, B or M -- alternate keys along the bottom row -- thrust any key on the middle letter row, fire any on the top letter row. Down is never set from the keyboard. Every read goes through OUT ($FD),A first (read_keyboard).
