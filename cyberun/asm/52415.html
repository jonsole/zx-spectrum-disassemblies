CCBF: The landscape's graphic-offset table
Six bytes for each piece direction 0 to 8 (directions 7 to 13 use 0 to 6's rows, 14 and 15 rows 7 and 8: the code in landscape_step_loop that finds the row). The byte at the row plus twice the column's variety (0-2, from column_varieties), plus one if the fine scroll is not 0 (draw_landscape then starts the table one byte on), is the offset into the piece's graphic at which its POP blitter starts: so each column of a flat run can show one of three stretches of the ground's graphic.
