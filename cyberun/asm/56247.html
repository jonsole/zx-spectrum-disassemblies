DBB7: Draw a sloped step cut off by the left edge
Used by the routine at step_dispatch.
Reached through step_dispatch (dispatch 8) for a sloped step of a piece running right that hangs over the play area's left edge (slope_step_at_left_edge). HL moves to column 1 of the same character row; the first patched JR decides whether one or two graphic bytes are skipped (INC SP), so that the first byte popped belongs in column 1; the second decides how much of each row pair is written: displacement 0 the last two columns, $2C the last column of a two-byte step, $30 the last column of a three-byte step. A POP at the end of each row pair keeps the graphic in step. Afterwards the next step's column comes from move_across_kept.
This was code typed as text and data in the first code map, before the staged tours ran it.
