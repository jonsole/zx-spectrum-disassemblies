DBFD: Draw a mirrored sloped step cut off by the left edge
Used by the routine at step_dispatch.
Reached through step_dispatch (dispatch 11) for a sloped step of a piece running left (directions 4-6 and their ceilings) that hangs over the left edge. Those directions are drawn as mirror images: each byte is looked up in the bit-reversing table bit_reverse_table with B = its page and C = the byte, so the row count lives in B' and the loop switches register sets. HL goes to column 1; INC SP and the first patched JR skip one or two graphic bytes; the second patched JR (displacement 0, $26 or $2A, set by slope_step_at_left_edge) picks how many columns of each row pair are written.
This was code partly typed as data in the first code map.
