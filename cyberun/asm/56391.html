DC47: Draw a mirrored sloped step cut off by the right edge
Used by the routine at step_dispatch.
Reached through step_dispatch (dispatch 5) for a sloped step of a piece running left that crosses the right edge. Like blit_mirrored_left_clip it mirrors each byte through the table bit_reverse_table and keeps the row count in B'. The patched JR (displacement set by use_mirrored_right_clip: 0 for two columns, $26, $27 or $28 for one, by how many pairs must be passed) decides how many of the step's columns are written.
This was code partly typed as data in the first code map.
