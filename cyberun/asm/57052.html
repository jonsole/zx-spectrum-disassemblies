DEDC: Current-piece record
Five bytes, addressed through IX while a piece is drawn: +0, +1 the screen x and y of the latest step set up (+1 is cleared at the start of each piece, so zero means none yet), +2 the number of steps drawn, +3 the direction (0-15). +4 is not used here. test_landscape_at and hit_block use the same bytes as scratch.
current_piece DEDC DEFS $05
