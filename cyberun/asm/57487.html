E08F: Bring in the map's objects for the window's two map columns
Used by the routine at load_map_window.
The things lying in the world are listed column by column: map_objects_per_column holds a count for each map column, map_object_kinds one byte per object (bits 0-5 its kind, bit 7 set once it is gone), and map_object_places two position bytes per object. The index of column view_column's first object is the sum of the counts before it; spawn_objects_from_list brings in that column's objects, then the next column's (right_map_column), restarting at object 0 when the column wraps to 0. Last, slots still free get +$10 cleared.
