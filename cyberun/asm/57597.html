E0FD: Object kinds: slot flags
One byte per kind (0-16), read by spawn_objects_from_list. Bits 7-5 go to bits 3-1 of the slot's +$18; bit 4 set makes the object an animated one, graphic $1B instead of $0D, with its frame byte and frame range from object_part_pairs (at the offset in the low four bits) and +$15 set to $80 so that animate_object animates it: kinds 4, 5, $0C, $0E and $10 (whose byte is $10: bit 4 set and offset 0, frames 0 and 1 like kind 4 -- the lamp).

E10D DEFB $10
