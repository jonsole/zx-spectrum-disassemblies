E114: Bring the objects of one map column into free ground-object slots
Used by the routine at spawn_column_objects.
For each of B objects: skip it if gone (bit 7 of its kind byte, or bit 6 for player 2: play patches the BIT), if its map row is not one of the window's two, or if a slot at ground_objects already holds it; otherwise take the first free of the first three slots (the fourth if none is), set it up (free_object) and fill it in from the object's two position bytes -- bits 7-2 of the first are the y (less one), bits 1-0 of it and bits 7-5 of the second the x, bits 4-0 of the second the map row -- with graphic $0D, kind (+$13), its colours from object_kind_bytes (+$0D), the flags from object_kind_flags (+$18) and the object's index (+$18 low bits, +$19) so it can be marked gone later.
Input
A Number of objects (none if 0)
B Same
C Map column
HL Object's kind byte (in map_object_kinds)
IX Object's position bytes (in map_object_places)
