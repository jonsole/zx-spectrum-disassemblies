E216: Address of a map cell
Used by the routine at read_map_cell.
Map rows are numbered from 1: row H is at landscape_map + (H - 1) * $60 (rows 0 and 1 give the same address; read_map_cell treats row 0 as empty). The column wraps: $FF becomes 95 and 96 becomes 0. C is left holding the wrapped column.
Input
HL Column (L), row (H)
DE $60
Output
HL Address in the map
C Column, wrapped
map_cell_address E216 LD C,L Row.

E21A LD HL,landscape_map
E21D JR Z,map_cell_address_1
