E41B: The current terrain piece's direction, and a flag of the collision-box builder's
For the landscape: $FF for a piece that climbs to the right (directions 0 to 3, 7 to 10, 14), 1 for one that climbs to the left. Set by set_piece_shape, turned round by fill_behind_moving_piece when a piece reverses, and read throughout the landscape drawing (landscape_step_loop, slope_step_at_right_edge, after_step_drawn and others).
place_collision_box borrows it as well: set to 1 there, it says the part to the right is still to test, and next_part clears it when it does so. The code map took it for an unused byte.
