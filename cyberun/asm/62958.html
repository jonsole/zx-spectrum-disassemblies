F5EE: The current player's add-ons (+7 to +15): the first slot
Nine bytes, one per add-on the ship can pick up, each 0 or the add-on's own number (1 to 9), set by draw_ship when one is fitted. build_ship_sprite builds the ship's picture (ship_picture) from them. The ones the code reads by name are entries of their own: addon_two, addon_four to addon_nine. This one is read by collect_pickup, build_ship_sprite and draw_ship.
