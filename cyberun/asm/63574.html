F856: Build the bit-reversed table at bit_reverse_table
Used by the routine at sprite_buffer_two.
Jumped to at the end of build_shift_tables, after build_shifted_pieces has run: bit_reverse_table + n gets n with its bits in the opposite order, for mirroring graphics: the ship when it faces left, the landscape's left-climbing pieces (blit_mirror_two, blit_mirror_one), and the sprite routines mirror_ship_sprite, draw_ship, blit_mirrored_left_clip and others. It overwrites the start-up routines from bit_reverse_table to shift_slope_piece's end, which are done with by then; the code map shows them because the snapshot was taken before the game ran.
