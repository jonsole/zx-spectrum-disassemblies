F895: Read a slope piece's header
Used by the routine at shift_slope_piece.
For shift_slope_piece: a slope's header is three bytes -- the number of rows in each variant, halved and rounded up (to row_count, and row_count_spare to reload it), the number of pairs of rows (row pairs to scratch_count and ground_cell), and the width in bytes (C). A flat piece's header is the last two of these (entered at its fourth instruction by shift_flat_piece). D is set to $FA, the first high page of the shift tables.
Input
HL the header
Output
HL the graphic
C its width in bytes
D $FA
