B734: Where the object templates are kept while the game runs
The start-up (START) copies 932 bytes here from TEMPLATES_TAPE: the templates for object types 0-$38, 11 bytes each; from offset 630 (LARGE_TEMPLATES), those for types $46-$54, 9 bytes each; and from offset 784 the patches for the codes $E6 up in a room's object list, six bytes each. The patches' base (PATCHES, offset 778) is where code $E5 would find its entry: PATCH_RECORDS in DO_ROOM_COMMAND counts from there. On the tape these bytes are leftover source text (lines 3970-4180, more of the object table's DEFB lines); the game never reads it.
