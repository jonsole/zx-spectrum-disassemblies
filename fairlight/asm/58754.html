E582: What the drawing variables start as in each room
Twenty bytes, copied to IY+$5F to IY+$72 by DRAW_CURRENT_ROOM before a room is drawn. The byte after them is not copied, and nothing reads it.
ROOM_DEFAULTS E582 DEFB $00,$00,$00,$00,$00 Into IY+$5F to IY+$68: the origin for the objects placed (0, 0, 0); a word other code uses (0); the point and the second point (50, 50 and 50, 50); $38 for the attributes, which DRAW_ROOM_RECORD replaces with 0 before anything reads it
E587 DEFB $32,$32,$32,$32,$38
E58C DEFB $00,$00,$00,$00,$00 Into IY+$69 to IY+$72: 0; lines to the screen, not the fill's map (IY+$6A: 0); the mode, the repeat count and the repeat's address (0); two bytes the object code uses (0); and $80 in IY+$72, which the code that moves things reads
E591 DEFB $00,$00,$00,$00,$80
E596 DEFB $00 Not copied
