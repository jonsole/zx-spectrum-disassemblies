E864: Find a pixel in the clean copy of the screen
Used by the routines at DO_ROOM_COMMAND and FILL_NEXT_SEED.
As SCREEN_PIXEL, then moved to the same place in the clean copy of the screen (LOADING_TUNE), 32K above the screen. The fill uses the clean copy as its map.
Input
B Row, from the bottom
C Column
Output
HL The byte in the clean copy
A The pixel's mask, and D the same
BUFFER_PIXEL E864 CALL SCREEN_PIXEL the screen byte and the mask
E867 LD D,A the same byte in the clean copy
E868 LD A,H
E869 ADD A,$80
E86B LD H,A
E86C LD A,D
E86D RET
