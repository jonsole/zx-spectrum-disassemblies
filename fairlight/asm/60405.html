EBF5: Print one character
Used by the routine at MAIN_LOOP.
Prints the character in A at the printing position (PRINT_X, PRINT_Y), by putting it into the one-character string after its own call to the printer (PRINT). LIFE's digits are printed this way (MAIN_LOOP).
Input
A The character (0 a space, 1-26 the letters, 27-36 the digits)
PRINT_CHAR EBF5 LD ($EBFB),A into the string
EBF8 CALL PRINT print it
EBFB DEFB $00 " "
EBFC DEFB $A4 End of the string
EBFD RET
