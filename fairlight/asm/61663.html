F0DF: Read a row of keys
Used by the routines at WAIT, CREATURE_UPDATE, KNIGHT_CONTROLS and MAIN_LOOP.
The author's INPUT. A selects the half-rows the way the high byte of IN A,($FE)'s address does, a 0 bit for each one read; what comes back has a bit set for each key held.
Input
A The half-rows to read
Output
A Bits 0-4, one for each key held
F Z if none is
INPUT F0DF IN A,($FE) Keys pull their bits low: turn them round
F0E1 AND $1F
F0E3 XOR $1F
F0E5 RET
