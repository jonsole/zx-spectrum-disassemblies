FF6A: Leftover characters
Bits of the ROM's user-defined graphics as the tape's maker left them: the ends of the letters C, D and E, which the ROM puts at the top of memory when it starts. The game never reads them. More of the same lie among the variables above, where the game does not use the bytes.
