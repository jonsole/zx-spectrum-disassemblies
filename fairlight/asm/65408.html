FF80: The game's variables
IY holds OBJECT_COUNT throughout the game, so most of these are reached as IY+n: the author's source text calls this base V, as in (V+3). Only two places move IY: ZOOMIN (ZOOMIN) points it at a chaser's target for a moment, and ROOMST steps it through the carried things. On the tape the first 61 bytes, up to OBJECTS_PLACED, hold the values a game starts with; the start-up copies them to the master copy (MASTER_OBJECTS) and a new game copies them back. The rest are set before they are read; on the tape many hold the ends of the ROM's user-defined graphics, like UDG_LEFTOVERS.
From POINT up the bytes have several lives, one at a time. While a room is drawn they are the drawing's state, twenty of them (from ORIGIN) reset from ROOM_DEFAULTS for each room. While an object is updated (CHE3D), POINT to WORK_HEADING are a copy of its record's first 19 bytes -- the author's T, as in (T+13) -- so that IY+$64 is the record's +0, IY+$6A its x (+6), IY+$6B its y (+7), IY+$6C its z (+8), IY+$70 its kind (+12) and so on; FOUND_RECORD (T+20), STEP_AXES, ASKED_DIRECTION, WORK_RECORD and RIDE_DIRECTION go with them. While a sprite is drawn (REDRAW_OBJECT) the same bytes hold the rectangle being redrawn, from a copy of +0 to +11, and the drawing's counters; and DRAW_LIST, lower down, takes a list of 30 bytes that runs over the printer's and the room drawing's bytes. Each use sets what it reads first.
The labels are for the use the object code makes of a byte where it reads it by address, and for the drawing's otherwise.
OBJECT_COUNT FF80 DEFB $00 Records in use, counted from FIXED_RECORDS: the six fixed ones, the knight's (7), then the carried things' and the room's
FF81 DEFB $02 Not used
STRIKES_AT FF82 DEFB $0B The low byte of the strike counter of the fighter FIND_OBSTACLE last passed ($98 to $9D)
THIS_RECORD FF83 DEFB $00 The number of the record being updated or drawn, counted from FIXED_RECORDS (the knight is 7)
FF84 DEFB $80 Not used
GRAVITY FF85 DEFB $23 $23, never written: its top six bits are ORed into the direction of a thing not rising -- bit 5, down (ANIMATE_AND_MOVE)
OPTIONS FF86 DEFB $10 Bit 3: the Kempston joystick is in use (9 turns it on and off)
MESSAGE FF87 DEFB $00 The message SHOW_MESSAGE is to show: 1 BLOCKED, 2 LOCKED, 3 TOO HEAVY; 0 none
MESSAGE_TIMER FF88 DEFB $00 MESSAGE_TIMER: passes the message stays up (10). Then two bytes not used; NO_RISE_MASK (IY+$0B), $EF and never written: ANDed with the direction of a thing not rising, it takes out bit 4, up (ANIMATE_AND_MOVE); and two more not used

THINGS_NOTED FF91 DEFB $00 Bit 0: a decoy is in the room (DECOY); bit 1: a thing of kind 11 is, which wakes the creature of behaviour 15 and lets the doors of room 61 be used (CHE3D, BUMPED)
CARRIED_WEIGHT FF92 DEFB $00 The weight of what is carried; 8 or more is too heavy

STRIKES_LEFT FF98 DEFB $00,$3E,$08,$08,$08,$08 Six fighters' strikes left, 4 each when a room is entered (FIND_OBSTACLE deals them out)

FFDC DEFB $52,$4A,$3C More of DRAW_LIST
ORIGIN FFDF DEFB $00 Added to x (+6) of each object the room places (IY+$5F-$61; room code $E4 $05)
ORIGIN_Y FFE0 DEFB $00 Added to its y, the height (+7)
ORIGIN_Z FFE1 DEFB $7C Added to its z (+8)
AWAY_FRAMES FFE2 DEFB $42,$42 How far the knight's frames for walking away (+x or +z) lie beyond those for walking towards the viewer, set just before FACING adds it
POINT FFE4 DEFB $7C The room drawing's first point: column. While an object is updated, its +0; in ROOMST, where the next carried record goes
POINT_ROW FFE5 DEFB $44 And row. While an object is updated, its +1
SECOND_POINT FFE6 DEFB $42 The second point: column. While an object is updated, its +2
SECOND_POINT_ROW FFE7 DEFB $00 And row. While an object is updated, its +14 as it was when the update began (CHE3D)
WORK_SPRITE FFE8 DEFB $00 While an object is updated or drawn, its sprite (+4, +5, a word); zero, and the byte the screen is cleared with, when a room is drawn (CLEAR_ROOM_SCREEN)
FFE9 DEFB $3C The sprite's high byte; then LINE_PAGE (IY+$6A): 0 to draw a room's lines on the screen, $80 in the clean copy (room code $E4), and while an object is updated, its x (+6)
LINE_PAGE FFEA DEFB $40
MODE FFEB DEFB $3C The room drawing's mode bits (room codes $C1-$CE, $E4 $04); while an object is updated, its y (+7)
REPEATS FFEC DEFB $02 How many times the room drawing repeats (room code $D5); while an object is updated, its z (+8)
FFED DEFB $42 Kept with REPEATS by room code $E1; while an object is updated, its x length (+9)
REPEAT_FROM FFEE DEFB $3C,$00 Where the repeat goes back to; while an object is updated, its height and z length (+10, +11)
WORK_KIND FFF0 DEFB $00 While an object is updated, its kind byte (+12)
WORK_DIRECTION FFF1 DEFB $FE Its direction (+13): 0 bounces, 1 rises, 2 -x, 3 +x, 4 up, 5 down, 6 +z, 7 -z; the sprite drawing's flags
WORK_BEHAVIOUR FFF2 DEFB $10 Its behaviour byte (+14)
DRAW_WIDTH FFF3 DEFB $10 A sprite's width in bytes, while it is drawn; while an object is updated, its timer (+15)
WORK_WEIGHT FFF4 DEFB $10 Its +16: 16 more than its weight, 0 if still; the length of the draw list while sprites are drawn
WORK_ANIMATION FFF5 DEFB $10 Its animation byte (+17); rows, while a sprite is drawn
WORK_HEADING FFF6 DEFB $10,$00 Its heading (+18); SP while CLEAR_512_BELOW borrows it; the fill's pointer to the row below
FOUND_RECORD FFF8 DEFB $00 The number of the record FIND_OBSTACLE found (the author's T+20); SP while CLEAR_ROOM_SCREEN borrows it; the fill's texture; a sprite row's bytes (DRAW_SPRITE)
DRAW_INDEX FFF9 DEFB $42 The record REDRAW_OBJECT is looking at
CLEAR_END FFFA DEFB $42 Where CLEAR_ROOM_SCREEN's clearing stopped
STEP_AXES FFFB DEFB $42 A move's axes: bit 0 x, 1 y, 2 z; 5 landed, 6 a climb, 7 into a door; the fill's pointer to this row
ASKED_DIRECTION FFFC DEFB $42 The direction a move asked for, before collisions changed it
WORK_RECORD FFFD DEFB $42 The record being updated; the fill's pointer to the row above
DRAW_COUNT FFFE DEFB $3C Counts down the draw list; the high byte of WORK_RECORD
RIDE_DIRECTION FFFF DEFB $00 The direction of what the mover has landed on; the last entry in the draw list at BUFFER_DA00 ($FF: none)
