71F3: Does a typed name fit an object's name?
The noun has to match; the adjectives need not be typed at all, and are accepted in either order -- it tries them as given, then swapped -- but one that does not belong rules the object out. Called directly on the small curious key: KEY, CURIOUS KEY, SMALL CURIOUS KEY and CURIOUS SMALL KEY all match; LARGE KEY, SMALL LARGE KEY and MAP do not.
Input
HL The typed name
IY The object's name
Output
F Z if it fits

71F4 PUSH HL
71F5 PUSH IY
71F7 CALL WORD_MATCHES The nouns must match, or it is not this object
71FA JR NZ,NAME_MATCHES_1
71FC LD A,$01 Note that the noun matched
71FE LD (NAME_FAILED),A
7201 CALL WORD_MATCHES Adjectives in the order typed? Then it fits, A = 0

7209 LD A,$00
720B JR Z,NAME_MATCHES_1
NAME_MATCHES_0 720D POP IY Otherwise start again from the beginning of both names...

7210 PUSH HL
