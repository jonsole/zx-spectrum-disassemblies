75D2: Where the parser goes for each class of word
One handler per token class, indexed by the class nibble shifted right three places at CLASS_DISPATCH and reached through JP (HL) -- so following branches never finds them, and they are code seeds. Twelve of the thirteen were reached in play. There is no entry for class $D: an unknown word never gets this far.
