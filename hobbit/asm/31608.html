7B78: Set the action's options from its pattern's flags
Four flags, from PATTERN_FLAGS. $B711: the action needs light at all -- set for every hands-on action, TAKE, OPEN, EXAMINE, LOOK and INVENTORY among them, which DO_ACTION refuses in the dark ("i see nothing here."), where the rest can still be done to what the actor carries. $B6FE: the first object is a place, not a thing -- ENTER and GO INTO. $B6FF: the same for the second object, set by no action in the game. $B70F: TAKE OFF, FOLLOW and JUMP ONTO, used by the object matching at $7D17 and not yet worked out.
PATTERN_OPTIONS 7B78 LD A,($B71E) $B711: needs light
7B7B AND $40
7B7D LD ($B711),A
7B80 LD A,($B71D) $B70F
7B83 LD B,A
7B84 AND $01
7B86 LD ($B70F),A
7B89 LD A,B $B6FE: the first object is a place
7B8A AND $80
7B8C JR Z,PATTERN_OPTIONS_0
7B8E LD A,$01
PATTERN_OPTIONS_0 7B90 LD ($B6FE),A
7B93 LD A,B $B6FF: the second is
7B94 AND $40
7B96 JR Z,PATTERN_OPTIONS_1
7B98 LD A,$01
PATTERN_OPTIONS_1 7B9A LD ($B6FF),A
7B9D RET
