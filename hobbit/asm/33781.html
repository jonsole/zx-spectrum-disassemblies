83F5: "you have mastered ... % of this adventure."
The score at $B6F7 is kept in tenths of a per cent, so a full game is 1000, and it is printed with one decimal place: hundreds only if not zero, then tens, a point, and units. Reaching the lonelands scores 25 (VISIT_SCORES), which is the 2.5% a first death there reports.
SHOW_SCORE 83F5 PUSH HL
83F6 PUSH DE
83F7 XOR A "you have mastered"
83F8 LD ($B701),A
83FB LD HL,$B454
83FE CALL RUN_MESSAGE_0
8401 LD HL,($B6F7) Hundreds, if any
8404 LD DE,$0064
8407 CALL DIGIT
840A CALL NZ,PRINT_CHAR
840D LD DE,$000A Tens
8410 CALL DIGIT
8413 CALL PRINT_CHAR
8416 LD A,$2E A decimal point
8418 CALL PRINT_CHAR
841B LD A,L Units
841C ADD A,$30
841E CALL PRINT_CHAR
8421 XOR A "% of this adventure."
8422 LD ($B704),A
8425 LD HL,$B462
8428 CALL RUN_MESSAGE_0
842B POP DE
842C POP HL
842D RET
