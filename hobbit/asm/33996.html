84CC: SAVE: four blocks to tape, then verified
Four headerless blocks through the ROM's SA-BYTES: the variables at $B6EB, the objects at $C11B, the timers and the characters at $CA84, and the rooms at $BA8A -- the same four START keeps a copy of. Then the tape is rewound and each block checked with the ROM's LD-BYTES in verify mode; an error says so and goes back to the game.
Three bytes of a character script at $C9E2, which the game rewrites as it runs ($A8CC), are carried in the first three of the variables block; DO_LOAD puts them back.
