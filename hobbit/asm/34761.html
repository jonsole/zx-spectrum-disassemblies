87C9: Print a character in the six-pixel font
A character six pixels wide seldom sits in one byte: each row is shifted to the pixel in C and, when it runs over, the rest put into the next byte along. The font is at $8822, from the space: $8722 + 8 times the character.
Input
A The character
HL The screen byte
C The pixel within it where the character starts
Output
HL The byte the next character starts in
C The pixel within it
