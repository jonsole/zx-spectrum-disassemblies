8B78: Busy-wait, 1000 times round
About 26000 T-states, or 7.4ms. SCAN_KEYBOARD calls it every time, so while the game sits at its prompt this is 88% of everything it does -- idle, not work, but it is also the reason a scan is too expensive to call from inside the drawing code as it stands.
DEBOUNCE_DELAY 8B78 LD BC,$03E8 1000 times round a four-instruction loop: about 26000 T-states
