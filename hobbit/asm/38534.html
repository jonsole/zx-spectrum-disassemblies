9686: Print the message at HL if there is one, or else the room's name
$9689 prints the name alone, from the record's bytes 2 to 7, the same way an object's name is printed.
Input
HL The description, or 0
F NZ if HL is not 0
IX The room's record
DESCRIPTION_OR_NAME 9686 JP NZ,RUN_MESSAGE_0
