9728: Is somebody else carrying this object?
Only asked for the player. If a character holds the object, the player is told so -- "the ... is carrying ...", with the two names -- and it cannot be acted on. Something the player has, however deep, and something held by a non-character, are fine.
Input
A The object, or $FF
Output
F NZ if another character has it
