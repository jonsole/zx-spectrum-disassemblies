9918: Move a character's script past this instruction
By DE bytes, and two more if the instruction has a fallback (bit 4).
Input
HL The instruction
DE Its length without a fallback
IY The character's slot
STEP_PAST 9918 ADD HL,DE Past the instruction
9919 BIT 4,(IX+$00) And its fallback, if it has one
991D JR Z,STEP_PAST_0
991F INC HL
9920 INC HL
STEP_PAST_0 9921 LD (IY+$02),L Save the new place in the slot
9924 LD (IY+$03),H
9927 RET
