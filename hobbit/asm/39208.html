9928: A script step: an action with objects, or a routine
Four bytes, then a 2-byte fallback if bit 4 is set. With bit 0 clear they are the action code and its two objects, tried as the character's own sentence. With bit 0 set, bytes 1 and 2 are the address of a routine instead: it is run once with printing off as a test, and only if it reports success by setting $B6FB is it run again for real.
A step that succeeds with bit 5 set takes the character out of the story: its slot is emptied and it never acts again.
