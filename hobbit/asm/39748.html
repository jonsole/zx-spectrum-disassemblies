9B44: Does the action make sense?
No if the actor would be doing it to itself, as either object, or doing it to one object with itself; TARGET_IS_PLACE and INSTRUMENT_IS_PLACE waive the checks; they are options of the action's pattern (PATTERN_OPTIONS), TARGET_IS_PLACE set for ENTER and GO INTO, whose object is a place, and INSTRUMENT_IS_PLACE for nothing at all. An action with no object always makes sense.
