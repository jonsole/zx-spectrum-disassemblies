9BCA: Find an object's record
The object number in A goes to FIND_RECORD against OBJECT_INDEX, and the record's address comes back in IX. Twenty-one routines use it.
Input
A The object number
Output
IX The object's record
GET_OBJECT 9BCA LD IX,OBJECT_INDEX Find the object's entry in OBJECT_INDEX
9BCE CALL FIND_RECORD
9BD1 PUSH HL Swap the entry's pointer into IX, keeping HL
9BD2 LD L,(IX+$01)
9BD5 LD H,(IX+$02)
9BD8 EX (SP),HL
9BD9 POP IX
9BDB RET
