9D37: The record of the room the current actor is in
Used by the routines at TOO_DARK and FIRST_EXIT.
ACTOR points at the object record of whoever is acting this turn -- the player or any other character -- and its location is at +$10, so the same code moves everybody.
Output
IX The room record
ACTOR_ROOM 9D37 PUSH AF
9D38 LD IX,(ACTOR) IX = the acting character's object record
9D3C LD A,(IX+$10) A = where that character is
9D3F CALL GET_ROOM IX = that room's record
9D42 POP AF
9D43 RET
