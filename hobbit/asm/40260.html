With DOING_IT set this returns and the handler goes on to do the action. With it clear it sets SUCCEEDED -- yes, it would work -- and drops its own return address, so the RET leaves the handler that called it.
FOR_REAL 9D44 LD A,(DOING_IT) For real: carry on
9D47 CP $01
9D49 RET Z
9D4A INC A A test: yes, it would work
9D4B LD (SUCCEEDED),A
9D4E POP BC ...and out of the handler
9D4F RET
