A0AE: Point at a location's exits
IX is left three bytes short of the first exit and BC = 3, so that ADD IX,BC steps to each in turn.
Input
A The location
Output
IX Its record + 7
BC 3
A0AE CALL $9BB1
A0B1 LD BC,$0007
A0B4 ADD IX,BC
A0B6 LD BC,$0003
A0B9 RET
