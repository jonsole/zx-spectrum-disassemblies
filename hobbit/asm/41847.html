A377: After the spider web is struck: the spiders start mending it
The web's record has this under key 0 straight after its handler for action 11, STRIKE WITH, so it runs whenever that does (see DO_ACTION). If the blow left the web broken -- flag bit 3 -- it can now be seen through (bit 5), "some spiders start mending the broken web.", and timer 1 is started: two turns later the web is whole again.
WEB_BROKEN A377 LD IX,($B708) Not broken: nothing
A37B BIT 3,(IX+$07)
A37F RET Z
A380 SET 5,(IX+$07) It can be seen through now
A384 LD A,($CA8B) Start timer 1
A387 LD ($CA8C),A
A38A LD HL,$B099 "some spiders start mending the broken web."
A38D JP RUN_MESSAGE_0
