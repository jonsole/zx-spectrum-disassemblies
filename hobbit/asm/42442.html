A5CA: Is this thing shut?
Flag bit 5 is being open to be seen into, and so to be got out of; Z if it is clear. A = 5, CLOSED, for SAY_STATE.
Input
IX The record
Output
F Z if shut
IS_SHUT A5CA BIT 5,(IX+$07)
A5CE LD A,$05
A5D0 RET
