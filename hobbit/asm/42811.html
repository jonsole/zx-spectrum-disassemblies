A73B: After Thorin is attacked: if he is dead, the curious key shatters
The small curious key opens the mountain's side door, and it is Thorin's. Killing him breaks it -- "the small curious key shatters." where the player can see -- which leaves the side door locked for good.
THORIN_KILLED A73B LD HL,THORIN_FLAGS Thorin not dead: nothing
A73E BIT 3,(HL)
A740 RET Z
A741 CALL ONLY_IF_DONE Only if it really happened
A744 LD IX,SMALL_CURIOUS_KEY The key is broken
A748 SET 3,(IX+$07)
A74C LD A,$02
A74E CALL BROKEN_OR_DEAD
A751 LD A,$02 "the small curious key shatters.", where the player sees it
A753 LD IY,PLAYER
A757 CALL ACTOR_IN_REACH
A75A RET Z
A75B LD HL,MSG_THE_SMALL_CURIOUS_KEY
A75E JP RUN_MESSAGE_HL
