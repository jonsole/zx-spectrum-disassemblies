B700: Whether the player has drunk the wine
Cleared at the start of a game and set by WINE_DRUNK. While it is set, PRINT_CHAR follows every S with an H: after the wine, the Lonelands' description comes out as "a gloomy empty land with dreary hillsH ahead". Tried, not only read -- the wine was moved into Bag End, DRINK THE WINE answered "you drink some wine." and set this byte, and a message printed before and after shows the difference.
DRUNK B700 DEFB $00
INPUT_STYLE B701 DEFB $00 Print in the input window, in capitals; also set while an action is refused
PRINTING_ON B702 DEFB $00 Printing on
NOUN_ONLY B703 DEFB $00 Names are printed as the noun alone
CAPITAL_NEXT B704 DEFB $00 The next letter printed is a capital
