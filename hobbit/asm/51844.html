CA84: The timers END_OF_TURN counts down
Ten 7-byte entries, ending at $FF: byte 0 is the timer's length in turns, and starting it is copying that into byte 1, the count -- WINE_DRUNK does exactly that for timer 7, and timer 9 restarts itself the same way. Bytes 2 and 3 are the routine to run when the count reaches zero. Byte 4 is how many turns before then to warn, and bytes 5 and 6 the routine to warn with. All of them are reached through $9B80's JP (HL).
This table and what follows it, $BF bytes in all, are copied aside by START and copied back on every new game; SAVE and LOAD take the same $BF bytes.
CA84 DEFB $02,$00,$FB,$A5,$00,$00,$00 Timer 0, 2 turns: the barrel reaches the long lake (A5FB); started by BARREL_THROWN
CA8B DEFB $02,$00,$5C,$AA,$00,$00,$00 Timer 1, 2 turns: the broken web is mended (AA5C); started by WEB_BROKEN
CA92 DEFB $05,$00,$10,$AB,$00,$00,$00 Timer 2, 5 turns: the web smothers anyone still in it (AB10)
CA99 DEFB $02,$00,$D9,$A4,$00,$00,$00 Timer 3, 2 turns: the goblins' door shuts (A4D9); started by GOBLINS_DOOR_OPENED
CAA0 DEFB $02,$00,$AA,$A7,$02,$AA,$A7 Timer 4, 2 turns: the deep bog, warning every turn (A7AA)
CAA7 DEFB $04,$00,$D5,$AA,$01,$B3,$AA Timer 5, 4 turns: the magic door opens a turn before it closes (AAB3, AAD5); started by MAGIC_DOOR_EXAMINED
CAAE DEFB $00,$00,$E0,$AA,$00,$00,$00 Timer 6: the ring slips off (AAE0); started by WEAR_RING at 2 to 10 turns, and run early by timer 5's warning
CAB5 DEFB $05,$00,$0B,$AB,$00,$00,$00 Timer 7, 5 turns: the wine wears off (AB0B)
CABC DEFB $04,$00,$3A,$AB,$03,$1F,$AB Timer 8, 4 turns: the eyes in the forest (AB1F, AB3A)
CAC3 DEFB $05,$00,$74,$AA,$01,$91,$AA Timer 9, 5 turns: the hole in the mountain's side (AA91, AA74)
CACA DEFB $FF End of the timers
