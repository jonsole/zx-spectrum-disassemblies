The Hobbit Bugs

JUMP ONTO the barrel jumps into a message
The barrel's own JUMP ONTO handler, AA27, refuses a jump from anywhere but directly above it. Where a way to the barrel exists but is not down, it does JP NZ,$B301 -- and $B301 is the message "you cannot jump onto the ... from here", not code. It was surely meant to be LD HL,$B301 and JP RUN_MESSAGE, as the line before it does. A quick test from the great halls beside the cellar did not reach it, because the parser will not name a barrel in another room; whether anything can reach it is not worked out.
FILL looks as though it can never work
The barrel's FILL WITH, 8F69, fetches a fresh water and puts it in the barrel with the objects swapped, through PUT IN (924F). But PUT IN begins with the last part of CAN_LIFT, which refuses a liquid -- and the water is a liquid. As read, then, filling the barrel is always refused. This has not been confirmed in play.
Code nothing reaches
Seven stretches of the game read as code but nothing calls them, jumps to them or names them in a table the game uses: special word slot 0's handler with the code before it (82FD), an OPEN for the wood elf alone (A536), a routine that would wipe an exit (A70A), one that finds what an object holds (A1AE), and three fragments (78FB, 9030, 92E8). They are left as data here, with what they would do said beside them.
