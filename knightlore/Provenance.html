What this is built from
The code map -- which bytes are instructions, which are data, and what the routines are called -- is derived from the Knight Lore disassembly by tcdev (2017), as converted to SkoolKit form by Michael R. Cook (2019). Only that factual layer is taken. None of their prose is reproduced: the commentary here is written from the code in this build.
On reuse
Neither of those works carries a licence, so they are treated here as reference and credit only. Knight Lore itself is copyright 1984 Ultimate Play the Game, and was designed and written by Tim and Chris Stamper. This repository contains no bytes of it -- run the build against a snapshot you own and it produces the disassembly locally.
Why the map can be trusted
It is not taken on faith. Every byte the map describes is disassembled and reassembled on each build and compared with the snapshot, so a boundary in the wrong place shows up as a mismatch rather than as quiet nonsense. The build also checks that every label and every hand-written comment lands on an instruction boundary, because SkoolKit will silently resume decoding from the middle of an instruction if one does not.
