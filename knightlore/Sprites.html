Knight Lore Sprites

Every sprite in the game, drawn from its own bytes the way print_sprite reads them: a header holding the width in bytes (bits 0 to 3) and the height in rows, then a mask byte and an image byte for each cell, bottom row first. Where a mask bit is set the sprite is solid, black or white by its image bit; where it is clear the background shows through, which is how objects overlap in depth without being drawn in any special order. The game flips sprites in place when an object faces the other way (vflip_sprite_data), and the header's top two bits say which way the data lies at the moment; each is shown here the way round it was drawn.

Beside each sprite are the object types that use it: the type is the object's own first byte, and indexes the table at sprite_tbl. See the objects for what each type is.
