B096: Object handlers, indexed by type
188 words, one per object type. The type byte of an object record is also its sprite number -- sprite_tbl has one word per type in the same order -- so one byte chooses both what an object does and what it looks like, and a handler animates its object by changing its type. jump_to_upd_object jumps through this.
Several types are drawn only in the status panel and never occupy the object table: the sun, the moon, the ends of their frame, the panel and border pieces and the lives icon. Their entries point at a bare RET or at a routine that only sets drawing offsets. Types 0 and 1 are not objects at all but the states of a free slot.
