B683: Dropping block (type 91)
The dropping_block (dropping_block). It sinks while something stands on it, one unit a frame, and stops when it lands on what is underneath. Bit 3 of +13 is set by the collision code (adj_for_out_of_bounds) on whatever an object lands on, so it is the "someone is standing on me" flag; this handler clears it every frame, so the block stops sinking the moment the weight steps off.
