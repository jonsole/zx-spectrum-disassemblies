B83F: Fire standing still (types 176 and 177)
The fire block (fire). It stays put and flickers: every other frame it flips between types 176 and 177 and, at random, mirrors itself.
The every-other-frame test uses $5BBC, which the object loop sets to the frame counter and then increments before each object. Its bit 0 therefore alternates from frame to frame and from one record to the next, so neighbouring fires take turns.
