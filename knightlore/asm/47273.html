B8A9: Start the cauldron bubbles
Used by the routine at end_of_frame.
Called once a frame from end_of_frame. In the wizard's room, room $88, it puts the bubbles into object record 3 if that record is empty and the game is not already won ($5BC3). Records 2 and 3 are where the special objects found in a room go; in this room the code that drops an object only considers record 2, which leaves 3 for the bubbles.
