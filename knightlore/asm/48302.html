BCAE: Print BCD numbers in the standard font
Used by the routines at game_over_summary, print_charms_and_show, print_percent_two_digits, print_days and print_lives.
Points the font pointer at $5BC7 at the standard font and prints each nibble as a character -- the digits are the first ten glyphs, so a BCD nibble is its own character code. No attributes are touched.
Input
DE the first byte of the number
B how many bytes: two digits each, high digit first
HL where in the buffer at screen_buffer the first digit's top row goes
print_BCD_number BCAE PUSH HL
BCAF LD HL,font
BCB2 LD ($5BC7),HL
BCB5 POP HL
