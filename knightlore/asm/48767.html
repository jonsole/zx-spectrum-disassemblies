BE7F: Print one 8x8 character into the buffer
Used by the routines at print_BCD_byte, print_BCD_lsd, print_text_char and print_text_last.
The glyph is at $5BC7 plus eight times the code. Rows go downwards on the screen, which in the buffer is 32 bytes lower each time. Rather than keep the start address, it adds $0101 at the end: eight rows of -32 is -256, so +257 lands on the next cell to the right of where it began.
Input
A the character code
HL the buffer address of its top row; on exit, one cell to the right
print_8x8 BE7F PUSH BC
BE80 PUSH DE
BE81 PUSH HL
BE82 LD L,A DE = the glyph
BE83 LD H,$00
BE85 ADD HL,HL
BE86 ADD HL,HL
BE87 ADD HL,HL
BE88 LD DE,($5BC7)
BE8C ADD HL,DE
BE8D EX DE,HL
BE8E POP HL
BE8F LD B,$08
