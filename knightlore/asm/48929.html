BF21: Start the sparkle an object vanishes in
Used by the routines at upd_92_to_95, upd_player_bottom and upd_player_top.
Turns the object in IX into type 112, the first frame of the sparkle, and sets bit 1 of +$07 so the collision code leaves it alone. Used by the player's own handlers when the player dies, and by upd_92_to_95 (types 92 to 95).
