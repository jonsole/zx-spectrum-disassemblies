BFDB: Scratch object record for the panel
A 32-byte object record, laid out like those in the object table, that the panel code fills in to draw a sprite on its own: type at +$00, the flip flags at +$07, the pixel position at +$1A (x) and +$1B (y). print_sprite writes the drawn width and height back to +$18 and +$19. Used for the border, the panel, the lives icon and the carried objects.
sprite_scratchpad BFDB DEFB $8A,$00,$00,$00,$00,$00,$00,$00
