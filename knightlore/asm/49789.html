C27D: The charms the wizard wants, in order
Fourteen kinds, 0 to 6 (the charm's type AND 7), each appearing twice. shuffle_objects_required rotates the list left by 4 to 7 places at the start of a game, choosing by the seed at $5BA0. The list is rotated in place and never put back, so the first game after loading can ask for only four orders, and later games rotate on from wherever the last one left it. Every game wants the same fourteen, two of each kind; only the order changes. ret_next_obj_required indexes it by the number already added.
