C2CC: Start the final animation
Used by the routine at add_obj_to_cauldron.
Called by add_obj_to_cauldron when the fourteenth object has gone into the cauldron. It sets the game-complete flag at $5BC3, which from now on stops the sun and moon (display_sun_moon_frame) and with them any further transformation, the player's input (check_user_input) and death. Then it clears the room for the ending: object records 3 to 13 are marked for erasing and given type 1, which the renderer turns into an empty record once the old image has been wiped (see calc_pixel_XY_and_render), and every plain stone block (type 7) further up the table becomes type 131, whose handler (upd_131_to_133) lifts it into the air.
Input
IX the object that has just reached the cauldron (preserved)
prepare_final_animation C2CC LD A,$01 the game is complete
C2CE LD ($5BC3),A
C2D1 PUSH IX
C2D3 LD IX,$5C68 from record 3 at $5C68, eleven records of 32 bytes
C2D7 LD DE,$0020
C2DA LD B,$0B
Which things records 3 to 13 hold in the wizard's room depends on the room data and has not been worked out record by record.
