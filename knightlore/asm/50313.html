C489: Set up one special-object entry
A table entry is nine bytes: +0 the type, 0 once the object has been collected; +1 to +4 where it starts, as x, y, z and room; +5 to +8 where it is now, in the same order. Here the type is written and the starting position copied to the current one.

HL the entry
E the rotating kind
