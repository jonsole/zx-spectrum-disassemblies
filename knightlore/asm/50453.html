C515: Fill a rectangle of bytes
Used by the routines at display_object, show_carried_slot, display_frame, colour_panel, fill_sun_moon_colour and wipe_rect.
Rows are 32 bytes apart, which suits both the buffer at D8F3 and the attribute file.
Input
HL the top-left byte, in the screen buffer or the attributes
B the width in bytes
C the number of rows
A the value to fill with
