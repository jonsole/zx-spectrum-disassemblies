C7DB: Is the player in the doorway?
Used by the routine at arch_check_doorway.
For each of records 0 to 3 that is in use and has bit 3 of +$07 set (the player's two records), sets bit 0 of +$07 if it is within the doorway's limits. handle_exit_screen will let the player leave the room only while that bit is set, and clears it when it does.
Input
IX the pillar's record, holding the arch's middle at +$09 to +$0B
L how near along x
H how near along y
chk_plyr_spec_near_arch C7DB LD IY,$5C08 records 0 to 3
