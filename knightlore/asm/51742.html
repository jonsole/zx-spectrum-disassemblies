CA1E: Which way does the object face?
Used by the routines at chk_facing_N, chk_facing_E, chk_facing_S, chk_facing_W and dispatch_on_facing.
Builds the facing code from the two bits that store it: bit 6 of +$07 (the sprite is mirrored) becomes bit 1, and bit 3 of the type (front view) becomes bit 0. So 0 is W, 1 E, 2 N and 3 S.
Input
IX the object
A on exit, the facing: 0 W, 1 E, 2 N, 3 S
