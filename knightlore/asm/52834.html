CE62: List the objects to be drawn this frame
Used by the routine at end_of_frame.
At the end of a frame, writes to objects_to_draw the index (0 to 39) of every live object whose redraw flag is set, in table order, and an $FF after the last. render_dynamic_objects wipes from this list and calc_display_order_and_render draws from it.
list_objects_to_draw CE62 PUSH IX IX = object 0, HL = the list, C = index
CE64 LD B,$28
CE66 LD DE,$0020
CE69 LD IX,$5C08
CE6D LD HL,objects_to_draw
CE70 LD C,$00
