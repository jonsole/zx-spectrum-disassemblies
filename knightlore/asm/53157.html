CFA5: The other object must be drawn first
IY is behind the candidate, so it becomes the candidate instead -- unless it is already in the chain of objects that have been candidates since the last draw (candidate_chain), in which case the order has gone round in a circle and break_order_cycle draws it straight away.
iy_goes_first CFA5 LD HL,($5BCF) C = IY's index, from its entry in the list
CFA8 DEC HL
CFA9 LD C,(HL)
CFAA LD DE,candidate_chain search the chain
