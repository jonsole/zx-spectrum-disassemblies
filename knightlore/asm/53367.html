D077: Kempston joystick
Used by the routine at check_user_input.
The Kempston interface answers on port $1F with the stick's switches active high: bit 0 right, 1 left, 2 down, 3 up, 4 fire.
kempston D077 IN A,($1F) read the stick
D079 LD C,$00
D07B BIT 0,A right: bit 1
D07D JR Z,kempston_left
D07F SET 1,C
