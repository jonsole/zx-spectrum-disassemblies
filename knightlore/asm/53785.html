D219: Mark the player's room as visited
Used by the routine at build_room.
$5BE8 to $5C07 is a 256-bit map of the castle, a bit per room number. The byte is the room number divided by 8; the bit number is the bottom three bits, and since SET takes its bit number in the opcode, the second opcode byte of the SET n,(HL) near the end of this routine is rewritten before it runs. calc_and_display_percent counts the bits for the percentage shown when the game ends.
