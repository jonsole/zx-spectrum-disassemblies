D3E2: Clear the object records from DE to the end of the table
Used by the routines at find_screen, next_bg_obj_sprite and end_of_fg_objs.
Every way out of the room builder ends here, so the records a room did not fill are left empty -- byte 0, the graphic, is 0 -- and the object walk at onscreen_loop skips them.
Input
DE the first record to clear, a whole number of records below font
zero_end_of_graphic_objs_tbl D3E2 LD HL,font done when DE has reached font, the end of the object table
D3E5 AND A
D3E6 SBC HL,DE
D3E8 RET Z
D3E9 LD B,$20 clear one 32-byte record and go round
D3EB CALL zero_DE
D3EE JR zero_end_of_graphic_objs_tbl
