D704: Draw one object from the render list
Used by the routine at render_obj.
Called by render_obj for each object in depth order. Graphic 1 is not drawn: the record is emptied instead, by setting its graphic to 0, which frees the slot. That makes graphic 1 look like a marker for an object on its way out, but what sets it has not been traced from this range.
Input
IX the object
calc_pixel_XY_and_render D704 LD A,(IX+$00) graphic 1?
D707 CP $01
D709 JR NZ,project_and_draw
D70B LD (IX+$00),$00 empty the record
D70F RET
