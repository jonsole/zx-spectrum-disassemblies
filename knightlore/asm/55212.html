D7AC: Jump into the row, then the shifted run
The JR's offset byte is patched by patch_sprite_rows: back into the aligned run for a byte-aligned sprite, into the shifted run below for any other. Each shifted unit is 16 bytes of code for one source byte. The left part of the mask and image, looked up on page H, finishes the byte in A, which is stored; the right part, on page H + 1, starts the next buffer byte, which is left in A for the next unit. The last spill is stored after the fifth unit.
