Knight Lore Trivia
  • Forty objects, thirty-two bytes each
  • Every room is one of three sizes
  • Facing west is facing east, reversed
Forty objects, thirty-two bytes each
The object table is exactly $5C08 to $6108, and $6108 is the first byte of the font. The loop at ret_from_tbl_jp detects the end of the table by comparing IX with the address of the font rather than with a count, so the two are the same number by construction.
Every room is one of three sizes
A room record does not carry its dimensions; it carries an index into the three-entry table at room_size_tbl. The castle is large but it is built from three box sizes.
Facing west is facing east, reversed
Among the tables the game builds at start-up (build_lookup_tbls) is the bit-reversal of every byte value, at reverse_bits_tbl. Mirroring a sprite horizontally is then a table lookup per byte, which is how the game gets a knight walking west out of the artwork for one walking east without storing it twice.
