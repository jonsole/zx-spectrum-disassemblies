5E00: Where the loader enters the game
Used by the routine at LOADER.
The loader jumps here once the game is in place. Interrupts are already off; the game keeps them so, and starts at START.
ENTRY 5E00 DI interrupts off (the loader has done it already)
5E01 JP START to the start
