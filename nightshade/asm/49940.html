C314: Print B bytes of BCD from DE, two digits a byte
Used by the routine at PRINT_PERCENTAGE.
With the digits' font (FONT), whose first character is 0, so a digit's value is its code. Each digit's cell is coloured with A' (PRINT_CHAR_COLOURED). PRINT_BCD_LOW starts with the first byte's lower digit, for an odd number of digits -- and without setting the font (see PRINT_PERCENTAGE).
Input
DE the first byte
B how many bytes
HL the screen address
A' the attribute
