C3D8: The sound effects
The addresses of the four effects' notes, then the notes: half-wave counts for CLICK. An effect of n notes plays the n bytes after its address, the last first (EFFECT_NOTE), so the byte at each effect's address is the previous effect's first note. Effect 0, four notes, a new cell with a building in it (VISIT_CELL); 1, five, the faster walk (SPEED_BONUS); 2, seven, the hits back (HITS_BONUS); 3, four, an object taken up (OBJECT_LYING) -- whose first note is read from past the table, the first byte of FIRE_SOUND's code, a very short half-wave (14, about 7850 Hz where the table's own notes run from 48 to 128): a squeak before three ordinary notes. Pentagram has the same table but starts only effects 0 and 1; here effects 2 and 3 are played, so the squeak is heard.
