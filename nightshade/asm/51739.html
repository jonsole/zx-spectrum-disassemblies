CA1B: Flash one of B attributes, and steady the rest
Used by the routine at FLASH_MENU.
Sets bit 7, FLASH, on the A'th of B attribute bytes from HL and clears it on the others; HL comes back just past the last. FLASH_MENU marks the chosen control method with it. This entry deals with the first byte; the loop is FLASH_NEXT_ONE. Alien 8's and Pentagram's TOGGLE_SELECTED.
Input
HL the first attribute
B how many
A which one flashes, counting from 0
TOGGLE_SELECTED CA1B AND A not the first
CA1C JR NZ,UNFLASH_THIS_ONE
This entry point is used by the routine at FLASH_NEXT_ONE.
FLASH_THIS_ONE CA1E SET 7,(HL) flash this one
