CB19: Print a character on the screen
Used by the routine at PRINT_CHAR_COLOURED.
Copies the character's eight bytes, from FONT_BASE plus eight times the code, onto the eight pixel rows of the cell, and gives HL back as it was. A space is printed as code $3C, a blank character in the font; the icons come in at PRINT_CODE, where a code of $20 is a character like any other. Alien 8's PRINT_CHAR drew into a buffer and moved HL on; this one draws on the screen and does not.
Input
A the code
HL the screen address of its top row
