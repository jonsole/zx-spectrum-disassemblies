D8D7: What each of the four objects starts as
Copied into each object's record by PLACE_OBJECTS, which then gives it its graphic and cell: the middle of the cell, standing still, half-size 8 each way. A thrown object is a copy of the knight's legs' record instead (KNIGHT_THROWS).
OBJECT_RECORD D8D7 DEFB $00 Object+0 graphic: 0
D8D8 DEFB $80 Object+1 U, low byte: 128
D8D9 DEFB $00 Object+2 U, high byte (the cell): 0
D8DA DEFB $80 Object+3 V, low byte: 128
D8DB DEFB $00 Object+4 V, high byte (the cell): 0
D8DC DEFB $00 Object+5 speed: 0
D8DD DEFB $00 Object+6 facing and turn count: 0
D8DE DEFB $00 Object+7 flags: 0
D8DF DEFB $08 Object+8 half-size in U: 8
D8E0 DEFB $08 Object+9 half-size in V: 8
D8E1 DEFB $00 Object+A step in U: 0
D8E2 DEFB $00 Object+B step in V: 0
D8E3 DEFB $F4 Object+C drawing offset x: 244
D8E4 DEFB $04 Object+D drawing offset y: 4
D8E5 DEFB $00 Object+E screen x: 0
D8E6 DEFB $00 Object+F screen y: 0
