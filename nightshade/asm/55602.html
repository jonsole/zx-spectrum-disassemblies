D932: What each of the four villains starts as
Copied into each villain's record by PLACE_VILLAINS, which then gives it its graphic and cell: the middle of the cell, speed 4, facing +V, half-size 16 each way. Its flags are 0 and nothing sets bit 5, so no villain ever homes in on the knight (STEER).
VILLAIN_RECORD D932 DEFB $00 Villain+0 graphic: 0
D933 DEFB $80 Villain+1 U, low byte: 128
D934 DEFB $00 Villain+2 U, high byte (the cell): 0
D935 DEFB $80 Villain+3 V, low byte: 128
D936 DEFB $00 Villain+4 V, high byte (the cell): 0
D937 DEFB $04 Villain+5 speed: 4
D938 DEFB $00 Villain+6 facing and turn count: 0
D939 DEFB $00 Villain+7 flags: 0
D93A DEFB $10 Villain+8 half-size in U: 16
D93B DEFB $10 Villain+9 half-size in V: 16
D93C DEFB $00 Villain+A step in U: 0
D93D DEFB $00 Villain+B step in V: 0
D93E DEFB $F4 Villain+C drawing offset x: 244
D93F DEFB $04 Villain+D drawing offset y: 4
D940 DEFB $00 Villain+E screen x: 0
D941 DEFB $00 Villain+F screen y: 0
