D942: The update routine for an object lying in the town (graphics 4-7)
Waits to be touched. Touched, it makes sound effect 3 for four turns and is taken up (PICK_UP_THING) into the first free place of the eleven the knight carries; with all eleven full, PICK_UP_THING returns without taking it and it stays where it lies.
Input
IX The object's record (OBJECTS)
OBJECT_LYING D942 CALL TOUCHING_KNIGHT Done unless the knight is touching it
D945 RET NC
D946 LD HL,$0304 Sound effect 3, for four turns
D949 LD (EFFECT_TIME),HL
D94C JP PICK_UP_THING Take it up
