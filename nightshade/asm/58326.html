E3D6: Mirror a sprite's data, whichever way it is stored now
Used by the routine at DRAW_VILLAINS.
Used only by the panel's villains (DRAW_VILLAINS), which copies the villains' sprites straight onto the screen and so needs them the right way round: it calls this when a sprite's mirrored bit is set, to turn it back. It never ran in the build's sessions, where no villain's sprite was stored mirrored when the panel was drawn. The stage-1 journal listed it with the upside-down flip; it is the mirroring half of TURN_SPRITE, which does run.
Input
DE The sprite
Output
DE The same
MIRROR_SPRITE E3D6 PUSH DE Push DE for the routine's end to pop; mirror the sprite
E3D7 JR MIRROR_SPRITE_DATA
