E5BA: Clear BC bytes from HL
Used by the routines at NEW_GAME and CLR_BITMAP_MEMORY.
The entry point FILL_MEMORY fills them with E instead. Also used at the start and at every new game (START, NEW_GAME) to clear the variables and the object records.
Input
HL The first byte
BC How many
Output
BC 0
CLEAR_MEMORY E5BA LD E,$00 The fill byte, 0
This entry point is used by the routine at CLR_ATTRIBUTE_MEMORY.
FILL_MEMORY E5BC LD (HL),E FILL_MEMORY: BC bytes from HL, all E
E5BD INC HL
E5BE DEC BC
E5BF LD A,B
E5C0 OR C
E5C1 JR NZ,FILL_MEMORY
E5C3 RET
