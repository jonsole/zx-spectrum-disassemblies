6F2F: Sprite for graphic 128
24 by 24 pixels.
The sprites, end to end from here to CONTROL, with the font among them (FONT). Each is a width byte (bits 0-3 the width in bytes; bit 7 set while it is stored upside down, bit 6 while mirrored, both toggled in place by FIND_SPRITE as objects face about), a height byte, then a mask byte and an image byte for each cell, the bottom row first. On the tape every sprite is the right way round.
