B278: Copy a rectangle of the buffer to the screen
Used by the routines at RENDER_DYNAMIC_OBJECTS and SHOW_CARRIED.
Works up the screen a row at a time, as SHOW_BUFFER does, for the areas RENDER_DYNAMIC_OBJECTS wiped and for the carried things on the panel (SHOW_CARRIED). The same as Knight Lore's.
Input
HL the buffer address of its bottom-left byte
DE the display address of the same byte

C the width in bytes
