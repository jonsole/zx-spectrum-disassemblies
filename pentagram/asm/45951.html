B37F: Buffer address of a pixel position
Used by the routines at SHOW_SCORE, RENDER_DYNAMIC_OBJECTS, DRAW_OBJECT, SHOW_CARRIED, ADD_SCORE, PRINT_TEXT_SINGLE_COLOUR and PERCENTAGE.
The buffer is plain rows of 32 bytes, the bottom line first, so the address is y * 32 + x / 8 from its start: BC shifted right three times. HL is kept. The same as Knight Lore's.
Input
C the pixel x
B the pixel y, counted up from the bottom of the screen
Output
BC the address in BUFFER
CALC_VIDBUF_ADDR B37F PUSH HL BC / 8 = y * 32 + x / 8
