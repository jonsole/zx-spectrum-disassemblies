B6DD: Fill a rectangle of bytes with A
Used by the routines at RENDER_DYNAMIC_OBJECTS and SHOW_CARRIED.
Rows are 32 bytes apart, each one on from the last: in the screen buffer (bottom row first) that is up the screen, in the attribute file down it. RENDER_DYNAMIC_OBJECTS clears in the buffer the rectangle an object leaves; SHOW_CARRIED clears a carried thing's place on the panel and then colours its attributes.
Input
HL the first byte
B the bytes in a row
C the rows
A the value
FILL_RECT B6DD LD DE,$0020 the row step
FILL_RECT_0 B6E0 PUSH BC fill a row
B6E1 PUSH HL
FILL_RECT_1 B6E2 LD (HL),A
B6E3 INC HL
B6E4 DJNZ FILL_RECT_1
B6E6 POP HL on 32 bytes, for the next
B6E7 ADD HL,DE
B6E8 POP BC
B6E9 DEC C
B6EA JR NZ,FILL_RECT_0
B6EC RET
