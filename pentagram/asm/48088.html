BBD8: Flash the chosen control method's line on the menu
Used by the routine at MENU.
Sets the FLASH bit on the colour of the line for the method in bits 1-2 of CONTROL and clears it on the other three (TOGGLE_SELECTED), then clears it on the next colour and sets it again if bit 3 of CONTROL is set. That next colour is the "0 START GAME" line's: Knight Lore's menu (flash_menu) has a line for directional control there, which bit 3 selects, and Pentagram kept the code but not the line. No menu choice sets bit 3, so the start line never flashes from here.
The colours are the first bytes of MENU_COLOURS; the title's, the first, is left alone. MENU calls this once before its loop and again after every pass, and the flash reaches the screen when DISPLAY_MENU rewrites the attributes.
FLASH_MENU BBD8 LD HL,$BBF2 the colour of the "1 KEYBOARD" line, the second in MENU_COLOURS
BBDB LD A,(CONTROL) flash the Ath of the four method lines, A the method from bits 1-2 of CONTROL
BBDE RRCA
BBDF AND $03
BBE1 LD B,$04
BBE3 CALL TOGGLE_SELECTED
BBE6 RES 7,(HL) HL is now on the start line's colour: no flash...
BBE8 LD A,(CONTROL) ...unless bit 3 of CONTROL (directional control) is set; this never ran in the build's sessions
BBEB AND $08
BBED RET Z
BBEE SET 7,(HL)
BBF0 RET
