BC7A: Unreached code: print a string that starts with its colour byte
These bytes are the Z80 code of Knight Lore's print_text_std_font and print_text: select the text font, work out the buffer address, and take the colour from the string's first byte, running on into TEXT_ATTR_ADDR. Nothing in Pentagram calls them, and they never ran in the build's sessions, so the code map leaves them as data; the comments give the instructions they encode. Pentagram's strings carry no colour byte: PRINT_TEXT_SINGLE_COLOUR takes the colour from PRINT_ATTR instead.
PRINT_TEXT_STD_FONT BC7A DEFB $E5 PUSH HL; LD HL, the text font's base; LD into FONT_BASE; POP BC
BC7B DEFB $21,$D5,$81
BC7E DEFB $22,$32,$A7
BC81 DEFB $C1
BC82 DEFB $C5 PUSH BC; CALL CALC_VIDBUF_ADDR; LD L,C; LD H,B; LD A,(DE), the colour byte; EX AF,AF'
BC83 DEFB $CD,$7F,$B3
BC86 DEFB $69
BC87 DEFB $60
BC88 DEFB $1A
BC89 DEFB $08
BC8A DEFB $13 INC DE, past the colour byte, then on into TEXT_ATTR_ADDR
