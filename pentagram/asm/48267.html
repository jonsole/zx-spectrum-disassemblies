BC8B: Find the string's first attribute cell, and print the string
Used by the routine at PRINT_TEXT_SINGLE_COLOUR.
The rest of PRINT_TEXT_SINGLE_COLOUR. The position is on the stack. In the alternate registers HL' becomes the attribute address of the first cell, while DE' is kept: the list printer in DISPLAY_MENU walks its list of colours with it. Then each character is drawn into the buffer by PRINT_CHAR, which leaves HL one cell to the right, and its cell in the attribute file is given the colour.
