CD75: The update routine for a block that can only fall; and for the table
Graphic 91, a block. The steps in U and V are cleared before it moves, so whatever pushed it this turn has no effect, and it only falls. It is also, with the player, one of the two things that set bit 7 of +17 on what they land on (MARK_STOOD_ON), so it can crumble a crumbling block or start a lift.
Graphic 73, the table, enters at SLIDING_TABLE: its template makes it pushable, and it keeps the step a push gave it, falls, and stops.
Input
IX the object record
HEAVY_BLOCK CD75 XOR A no sideways step: pushes are lost
CD76 LD (IX+$09),A
CD79 LD (IX+$0A),A
SLIDING_TABLE CD7C CALL DRAW_AT_L16_D12 the table's way in: its own drawing nudge
CD7F JR FALL fall, and stop
