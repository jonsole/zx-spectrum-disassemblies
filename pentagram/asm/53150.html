CF9E: Give a quest thing a new graphic, in its quest record and its object record
Used by the routines at COLLECTABLE and QUEST_ITEM.
Finds the quest record (QUEST_RECORDS) that has the old graphic and gives it and the object the new one, so the change lasts when he leaves the room (QUEST_OUT_OF_ROOM matches the records by graphic). If no quest record has the old graphic, neither changes.
Input
A the old graphic
C the new graphic
IX the object record
CHANGE_GRAPHIC CF9E CALL QUEST_RECORD_LOOP find the quest record with the old graphic; none: done
CHANGE_GRAPHIC_0 CFA1 CP (IY+$00)
CFA4 JR Z,CHANGE_GRAPHIC_1
CFA6 ADD IY,DE
CFA8 DJNZ CHANGE_GRAPHIC_0
CFAA RET
CHANGE_GRAPHIC_1 CFAB LD (IY+$00),C both get the new one
CFAE LD (IX+$00),C
CFB1 RET
