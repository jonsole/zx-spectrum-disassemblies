D67B: Beep: C waves of half-wave count B
Used by the routines at BLIP_BY_TURN, PAUSE_BEEP, EFFECT_NOTE, FOOTSTEP and PUFF_SOUND.
The common tail of the effects. CLICK leaves B as it found it, so every wave has the same pitch.
Input
B the half-wave count (0 is 256)
C the number of waves
BEEP D67B CALL CLICK C waves
D67E DEC C
D67F JR NZ,BEEP
D681 RET
